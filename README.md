# Image-Gallery
A practice project building a responsive image gallery using HTML and CSS, exploring image layouts, spacing, hover effects and Grid.
# Image Gallery

## About This Project

This project is part of my software and web development course. I'm using it to practise building an image gallery with HTML and CSS.

The aim is to create a clean layout that displays images neatly, works on different screen sizes and looks good without making the design too complicated.

## What I'm Working On

- **CSS Grid** – arranging images into a structured gallery layout.
- **Responsive design** – adjusting the number of columns to suit different screen sizes.
- **Image sizing** – using `object-fit` to keep images looking consistent.
- **Spacing and alignment** – using gaps, padding and margins to organise the gallery.
- **Hover effects** – adding simple effects when the user moves over an image.
- **Image borders and shadows** – experimenting with styling to improve the overall appearance.
- **Accessibility** – adding useful alt text to describe the images.

## Technologies Used

- HTML5
- CSS3

## What I've Learned

This project gives me the chance to practise arranging images with CSS and understand how to make a gallery look consistent across different devices.

I'm also learning how properties such as `grid-template-columns`, `gap` and `object-fit` affect the layout and appearance of images.

I'll continue improving the gallery as I learn more about CSS and responsive web design.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Resize the browser window to see how the gallery adapts to different screen sizes.
